# 0.1.0 — 首版 CLI

[English](0.1.0.md)

## 问题与逻辑变化

作者已有公开 skill，但缺少可安装命令来管理发布版本、调用本机宿主。本版增加五个命令、已审来源目录、稳定标签与提交、精确载荷校验、安全旁置所有权与事务、已知本地冲突检查，以及不存储模型密钥、不绕过权限的本机宿主启动；同时包含相应中英文用法、维护和恢复文档。

初始目录只含 aesthetic-design。按需抓取其九图公开发行，不含私有完整图片归档。新增作者 skill 和打包格式需要审查后发布目录、CLI 版本，不接受运行时任意 URL。

## 真实测试优先证据

2026-11-06 08:49:56 UTC，首个安装验收使用 Node 24.22.2 对最小无操作管理器运行：命令返回后，所选项目的 SKILL.md 仍不存在。预期退出0，实际测试退出1，`false !== true`；这是实际安装断言，不是缺失导入。随后实现使同一验收通过。

实现过程中，边界测试覆盖真实临时 Git 标签、载荷和文件系统转换。审查还暴露两项可观察兼容缺陷，各自在修正前增加回归：

- 合法、非同名的 Claude skill 省略 name 时，use 被阻止。实际测试因解析器要求明确 name 而失败；冲突检查采用 Claude 目录缺省名称后通过。登记来源包仍要求明确匹配的 name。
- 真实隔离进程组收到 SIGINT 后，包装进程退出却遗留管理锁。实际测试在 `lock remains = true` 处失败；信号处理修正后，同组 SIGINT 与仅父进程 SIGTERM 都完成、不重复转发 Ctrl-C，并释放锁。强制进程退出仍属于独立恢复情形。

夹具导入、配置失败不算业务 Red 证据。原始命令、时间、输出、退出码保存在公开包之外，共享 JSON 保留真实脱敏摘要。测试不替换 HOME、CODEX_HOME，不调用付费模型会话。

## 限制与回退

使用 macOS arm64、Node 24；未确立 Linux、原生 Windows、真实模型激活和分类准确率、全部宿主管理来源、同用户恶意文件系统竞态，以及真实硬件、断电持久性结论。普通异常恢复旧配对；中断事务按文档人工恢复。删除 journal 后新版已提交，因此清理失败保留新版，不回滚可能残缺的旧备份。

包没有运行时 npm 依赖或安装生命周期钩子。原创 CLI 代码、文档 MIT；安装 skill 及第三方内容保留原许可。回退后续 CLI 版本时，重新安装较早已验证标签并保留日志；不移动已发布标签，也不通过 CLI 降级强制 skill 降级。本实现没有发布仓库或其他外部状态。
